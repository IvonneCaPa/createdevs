# CreateDevs · Diseño web con voz propia

Portfolio web para presentar una selección de proyectos de diseño digital. La propuesta reúne trabajos editoriales, de servicios y culturales en una experiencia de una sola página, con una identidad visual oscura y editorial.

> Cada proyecto tiene su propio tono; el diseño ayuda a encontrar la forma de hacerlo sonar.

## El proyecto

El objetivo fue crear una presentación clara y atractiva de distintos trabajos, dejando que cada uno conserve su personalidad y facilitando que posibles clientes conozcan el proceso y contacten.

La experiencia combina una portada de bienvenida, proyectos seleccionados, una breve presentación del enfoque de trabajo y un formulario de contacto.

## Proyectos seleccionados

### Maria Dolors Camós · Editorial

Sitio para una psicoanalista y escritora. Una dirección visual sobria y literaria que prioriza la lectura y la trayectoria profesional.

[Visitar sitio](https://dolorscamos.com)

### Lorena Artist · Servicios

Landing para servicios de maquillaje drag, peluquería creativa, posticería y formación, con información de servicios y una llamada a reservar.

[Visitar sitio](https://lorenaartist.vercel.app)

### Queer Party · Cultura

Propuesta para una plataforma de fiestas y eventos queer, con una identidad colorida y una experiencia pensada para consultar eventos desde el móvil.

[Visitar sitio](https://www.queerparty.es/)

## Enfoque de diseño

- **Identidad editorial:** combinación de Playfair Display e Inter para equilibrar expresividad y legibilidad.
- **Paleta oscura:** fondos profundos, texto claro y acentos dorados.
- **Contenido primero:** secciones y jerarquías para presentar cada proyecto de forma sencilla.
- **Adaptabilidad:** estilos responsive para distintos tamaños de pantalla.
- **Interacción sutil:** navegación por anclas, desplazamiento suave y aparición progresiva de elementos al recorrer la página.
- **Accesibilidad:** estructura semántica, textos alternativos en imágenes y estados de foco visibles.

## Tecnologías

- HTML5
- CSS3
- JavaScript nativo para el año del footer y las animaciones de entrada
- Google Fonts

No requiere frameworks ni dependencias de instalación.

## Ver el sitio localmente

Abre `index.html` en un navegador o inicia un servidor local desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Después visita [http://localhost:8000](http://localhost:8000).
